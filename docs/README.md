# Shavin contributor docs

Guides for working on the open packages in this repository: `@shavin/ui`, `@shavin/cli`, `@shavin/mcp`, `@shavin/skills` and `@shavin/block-schema`.

Start with the root [README](../README.md), then [CONTRIBUTING](../CONTRIBUTING.md) (setup, sign-off, the four checks) and [AGENTS.md](../AGENTS.md) (the design rules every change follows). These pages fill in the rest.

| Page | Read it when |
|---|---|
| [Repository map](./repo-map.md) | You want to know where something lives, and which files are generated |
| [Primitives](./primitives.md) | You add or change a component in `@shavin/ui` |
| [Tokens and theming](./tokens-and-theming.md) | You touch colours, radius, shadows, motion or theme presets |
| [Responsive layout](./responsive-layout.md) | You build or review layouts, shells or headings |
| [Skills](./skills.md) | You edit agent skills or slash commands |
| [MCP server](./mcp-server.md) | You fix or add an MCP tool |
| [CLI](./cli.md) | You change `shavin init`, `add`, `check` or another command |
| [Block schema](./block-schema.md) | You work on block types or the open block catalogue |
| [Testing locally](./testing-locally.md) | You want to try the packages in a real app before a PR |

## Not covered here

Proprietary upstream parts of the monorepo and the hosted services are not open source, so they are not documented here. Ideas and bug reports for the open packages go in GitHub issues.
