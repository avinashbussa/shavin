# Page recipes

A recipe is a starting sequence, not a template to copy. It answers "what order do these sections go in, and why?" Pick the closest recipe, then swap or drop sections to fit the real content and mutate at least two knobs from `distinctiveness.md`.

Every recipe assumes ST5 (page shell) underneath. A validator checks that every ID below exists.

Contents: SaaS launch · Developer tool / open source · Documentation site · Editorial / magazine · Portfolio / studio · Pricing and conversion · Case study · Hybrid (product + docs + blog)

---

## SaaS product launch

**Arc:** attention → credibility → understanding → desire → decision → action.

| # | Section | Composition | Notes |
|---|---|---|---|
| 1 | Navigation | ST1 | One primary action |
| 2 | Hero | H1, or H2 if copy is long | Photo / mesh / video backdrop, or product UI |
| 3 | Proof bar | S1 or T3 | Pick one, not both |
| 4 | Core value | F3 (2–3 rows) or F6 | The "how it works" moment |
| 5 | Breadth | F2 | Only with ≥ 5 items of mixed priority |
| 6 | Voice | T1 | Specific outcome quote |
| 7 | Plans | P1 | Link to P2 if needed |
| 8 | Objections | Q2 | |
| 9 | Close | C1 | Same CTA wording as the hero |
| 10 | Footer | ST3 | |

**Rhythm:** quiet (S1) → loud (F3) → dense (F2) → quiet (T1) → dense (P1) → quiet (Q2, C1).

## Editorial / magazine

**Arc:** front page ranks; article pages absorb; archive lets people wander.

| # | Page or section | Composition | Notes |
|---|---|---|---|
| 1 | Front | ST1, E3 | Editors set the ranking |
| 2 | Article | E1 | 68ch column, breakout figures |
| 3 | Essay | E2 | Margin notes at `xl` |
| 4 | Archive | E4 | Year groups |
| 5 | Footer | ST4 | Signature close |

Prefer `open` or `ruled` treatments. Cards are the wrong default here.

## Hybrid (product + docs + blog)

**Arc:** one brand, three modes, one dominant treatment.

| # | Area | Composition | Notes |
|---|---|---|---|
| 1 | Marketing home | Use the SaaS launch recipe | |
| 2 | Docs | D4, D1, D2 | Switch to `ruled` |
| 3 | Blog | E3, E1, E4 | Switch to `open` |
| 4 | Shared frame | ST1, ST3 | Same nav and footer across modes |

Keep the tokens the same across modes and vary only the treatment and density. Shared brand, different jobs.
