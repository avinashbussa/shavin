## Quick Reference Commands

- **Regenerate everything**: `npm run regen` (generators in dependency order; commit any files it changes)
- **Verify (CI)**: `npm run verify` · **Tests**: `npm test` · **Evals**: `npm run eval`
- **Preview primitives**: `npm run playground` (http://localhost:3700)
- **MCP Server**: `npm run mcp`
- **Agent files**: `npm run agents:gen` regenerates AGENTS.md and CLAUDE.md from `packages/skills/agents/` and `packages/cli/src/templates/CLAUDE.md`
