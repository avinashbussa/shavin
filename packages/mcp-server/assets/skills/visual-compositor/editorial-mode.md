## Quick Reference

Editorial mode enables 8 advanced capabilities:

1. **Motion Architecture** — Scroll-triggered animations, parallax, easing curves
2. **Editorial Typography** — Fluid sizing with `clamp()`, extreme contrast ratios
3. **Z-Axis Depth** — 3D transforms, layered depth, grid escape
4. **Asymmetric Grid** — Golden ratio, intentional imbalance
5. **Section Transitions** — Diagonal clip-paths, overlapping sections
6. **Color Atmosphere** — Grain textures, glassmorphism, radial glows
7. **Theatrical White Space** — Breath sections, void minimums
8. **Hero Scale** — Full viewport height with `100dvh`
