Taste) reviewed and mapped against this library. Most already had a home in the existing
compositions; three gaps became new entries: **F8 Comparison Split**, **F9 Ecosystem / Integration
Diagram**, and **C5 Newsletter Capture Banner**. This file is the lookup — which real-world pattern
maps to which composition ID — kept separate from the compositions themselves so the compositions
stay generic and don't accumulate a growing pile of site-specific examples over time.

`NEW` entries below are chrome (nav slivers, a mega-menu footer) that already map cleanly to ST1 /
ST3 and needed no new composition.
